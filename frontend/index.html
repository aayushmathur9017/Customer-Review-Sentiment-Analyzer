About Project

Bank Muscat Customer Feedback & Sentiment Analytics System

🏦 Project Overview

The Bank Muscat Customer Feedback & Sentiment Analytics System is a data analytics and machine learning based application designed to analyze customer reviews and identify their sentiment as Positive, Neutral, or Negative.

🎯 Project Objective

The main objective of this project is to convert customer feedback into meaningful insights that can help identify customer satisfaction, service issues, and areas requiring improvement.

🤖 AI / Machine Learning Technology

The system uses Natural Language Processing (NLP) and a Machine Learning model to analyze customer review text.

  • Text preprocessing
  • TF-IDF feature extraction
  • Logistic Regression classification
  • Sentiment prediction
  • Confidence score calculation

📊 Data Analytics

The system provides analytical insights through KPIs, sentiment distribution, service-wise analysis, review history, and business insights.

  • Overall sentiment analysis
  • Service-wise sentiment comparison
  • Positive and negative feedback analysis
  • Customer review history
  • Business insights

🔄 System Workflow

  1. Customer review is entered into the system.
  2. Review text is processed using NLP.
  3. TF-IDF converts text into numerical features.
  4. Machine Learning model predicts sentiment.
  5. Prediction is stored in the SQLite database.
  6. Analytics dashboard displays useful insights.

🛠️ Technologies Used

  • Frontend: HTML, CSS, JavaScript
  • Backend: Python, FastAPI
  • Machine Learning: Scikit-learn
  • Data Processing: Pandas, NLP
  • Database: SQLite
  • Visualization: JavaScript Charts

📌 Project Scope

This project demonstrates how Artificial Intelligence, Machine Learning, and Data Analytics can be combined to transform customer feedback into actionable business insights for banking services.
